# CSS Bingo

In CSS Bingo, snippets of HTML code are shown with a portion of code highlighted. Participants look at their card for a CSS selector that would match the highlighted portion of the HTML.

CSS Bingo can be accessed at https://cmaissan.github.io/css-bingo/

## Generate Cards

To generate a set of bingo cards, select "Generate Cards" and enter the number of cards required. Then click "Print".

## Start Game

Once the bingo cards have been printed and distributed, select "Start Game" and set the number of seconds to delay between bingo calls. 

At any point in the game, if bingo is called click "Check" to display a list of the HTML code snippets shown, the matching selector and which letter it falls under.
